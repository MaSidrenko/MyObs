# Параллельное программирование
Параллельное  программирование - это подход к построению программ, при котором вычислительная работа выполняется одновременно (Одновременными потоками, задачами или процессами) для повышения производительности, пропускной способности или отзывчивости. В .NET под параллелизмом обычно понимают использование нескольких ядер CPU и/или многопоточность с помощью thread pool / tasks / PLINQ / async I/O

## Ключевые понятия
 1. Параллелизм - выполнение нескольких вычислений одновременно (на разных ядрах CPU)
 2. Конкурентность - структура программы, допускающая одновременно выполнение логических потоков, не обязательно одновременно (например, одномоментно на одном ядре, но логически параллельно)
 3. Гранулярность - размер единицы работы (чем крупнее - меньше накладных расходов на переключение контекста)
 4. Синхронизация - механизмы для корректного доступа к общим ресурсам. 

Отличие parallel от threading
Threading - низкоуровневая ручная работа
Task - абстракция над работой
Parallel и PLINQ - высокоуровневый параллелизм
