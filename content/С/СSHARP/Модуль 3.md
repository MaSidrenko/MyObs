# Многопоточность и асинхронность
## Многопоточность
Многопоточность - это способность программы выполнять несколько участков кода одновременно
## Многопоточность нужна: 
1. Выполнение задач параллельно (I/O операции, обработка данных);
2. Реактивность UI (Чтобы интерфейс не зависал);
3. Ускорение вычислений на многоядерных процессорах
4. Выполнение фоновых задач
## Потоки
Поток - минимальная единица  выполнения программы. Процесс может содержать один или много потоков.
Каждый поток имеет:
1. Стек;
2. Счётчик команд;
3. Состояние;
4. Приоритет;
5. Контекст выполнения;
## Создание потоков
На низком уровне поток создаётся системным API (Например, CreateThread в Windows);
В .NET поток создаётся объектом класса Thread (из System.Threading):
```
Thread t = new Thread(MyMethod);
t.Start();
```
## Приостановка, возобновление, прекращение потока
Методы Thread.Suspend/Resume/Abort - устарели. Могу повредить состояние ПО, привести к deadlock [[Модуль 4]]
Более современный подход - кооперативная отмена:
Используются:
1. CancellationToken;
```
CancellationTokenSource cts = new CancellationTokenSource();

Thread t = new Thread(() =>
{
    while (!cts.Token.IsCancellationRequested)
    {
        // code;
    }
});

t.Start();

// stop;
cts.Cancel();
```
1. Флаговых переменных;
```
bool isRunnig = true;

Thread t = new Thread(() => 
{
	while(isRunnig)
	{
		//code;
	}
});
t.Start();

isRunnig= false;
```
## Принудительное завершение потока
.Abort() запрещен. Корректный способ - дать потоку завершиться самостоятельно

## Приоритеты потоков
У каждого потока есть свойство:
```
thread.Priority = ThreadPriority.Highest;
```
Приоритет влияет только на планировщик ОС - это не гарантия порядка выполнения. 
Значение:
Lowest - Низкий
BelowNormal - ниже среднего
Nornal - средний(По умолчанию);
AboveNornal - выше среднего
Highest - высокий

4. Interloacked

## Первичные (foreground) и фоновые (background) потоки
1. Foreground(основные)
	1. Блокируют завершение процесса
2. Background (Фоновые)
	1. Не блокируют завершение процесса 
	2. Процесс завершается даже если фоновые ещё работают 
```
t.isBackground = true;
```

## Асинхронный вызов методов
В .NET асинхронность - это не то же самое, что и поток
Асинхронность - это способ не блокировать поток 
Используется async/await
```
async Task<int> DoWorkAsync()
{
	awit Task.Delay(1000);
	return 5;
}
```

## Остановка/возобновление
Thread.Suspend/Resume - считаются устаревшими и опасными
Корректный вариант - токены, флаги, события
## Что такое пул потоков?
Готовые рабочие потоки, которые ОС не создает заново. Применение - массовые, короткие задачи.
