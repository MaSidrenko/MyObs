# P/Invoke
Это механизм .NET, который позволяет вызывать ф-ции из нативных DLL (Обычно WinAPI). Большинство API P/Invoke содержится в двух пространствах имен: System и System.Runtime.InteropServices
![[Pasted image 20251211133558.png]]
Во 2 строке вызывается директива using для System.Runtime.InteropServices пространства имен, в котором хранятся все необходимые элементы. В 8 строке LibraryImport атрибут, который сообщает среде выполнения, что она должна загрузить неуправляемый двоичный файл, содержащий целевую ф-цию. 
В 9 строке работа P/Invole/ Она определяет управляемый метод имеющий точно такую же сигнатуру, что и неуправляемый. Объявление использует LibraryImport атрибут и partial ключевое слово, чтобы сообщить расширению компилятора, чтобы создать код для вызова неуправляемой библиотеки.
# Interop
Нужен для доступа к WinAPI, работе с драйверами/системными вызовами, использование старых C/C++ библиотек

# DLLImportAttribute 
![![С/СSHARP/#*Table]]
```
[DllImport("user32.dll", SetLastError = true)]
static extern int MessageBox(IntPtr hWnd, string text, string caption, uint type);
```

В данном случае импортируется user32.dll, и из нее берется метод MessageBox
