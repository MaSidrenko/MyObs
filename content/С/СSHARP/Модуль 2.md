## Что такое процесс
экземпляр выполнения программы. Когда ОС зупускает приложение, она создает новый процесс, который включает:
1. Исполняемый код ПО;
2. Выделенное адресное пространство
3. Набор ресурсов (открытые файлы, сетевые соединения, дескрипторы устройств);
4. Один или несколько потоков;
5. Информация ОС о процессе (PID, приоритет, состояние)

## Как создать процесс в .NET
```
Process p = Process.Start("notepad.exe");
```
## Дочерний процесс - что это?
Процесс, запущенный родительским. Может наследовать:
1. Переменный окружения;
2. Дескрипторы;
3. stdin/stdout;
## Разница между процессом и доменом приложения (AppDomain)
1. Процесс -> уровень ОС;
2. AppDomain -> уровень CLR;
3. Падение домена != падение процесса;
