# Основная информация
Память в C# делится на два типа стек(stack) и куча(heap). Параметры и переменные метода, которые представляют типы значений, размещают свое значение в стеке. Ссылочные типы хранятся в куче(heap).
# Стек
Стек представляет собой структуру данных, которая растет снизу вверх: последним зашел, первым вышел(last in first out).Время жизни переменных таких типов ограничено их контекстом. Физически стек - это некоторая область памяти в адресном пространстве.
Когда программа только запускается на выполнение, в конце блока памяти, зарезервированного для стека, устанавливается указатель стекаю При помещении данных в стек указатель переустанавливается таким образом, что снова указывает на новое свободное место.
Например у нас есть такая программа:

```
class Program
{
	static void Main(string[] args)
	{
		Calculate(5);
	}

	static void Calculate(int t)
	{
		int x = 6;
		int y = 7;
		int z = y + t;
	}
}
```
При запуске такой программы в стек будет выглядеть так:
![[Stack.png]]
При вызове каждого метода в стеке будет выделятся область памяти (Фрейм стека), где будут хранится значения его параметров и переменных.
# Куча
Куча представляет собой как неупорядоченный набор разнородных объектов. Физически это остальная часть памяти доступная процессу. При создании объекта ссылочного типа в стеке помещается ссылка на адрес в куче. Когда этот объект перестает использоваться, в дело вступает автоматический сборщик мусора: он видит, что на объект в куче нету больше ссылок, он удаляет этот объект и очищает память. 
Немного изменим предыдущий пример:

```
static void Calculate(int t)
{
	object x = 6;
	int y = 7;
	int z = y + t;
}
```
Теперь значение переменной x хранится в куче, а в стеке будет лишь ссылка на объект в куче:
![[Stack&Heap.png]]
# Составные типы
Рассмотрим ситуация, когда значимые типы и ссылочные типы представляют составные типы - структуру и класс.
Пример кода:

```
State state1 = new State();
Country country1 = new Country();

struct State
{
	public int x;
	public int y;
}
class Country
{
	public int x;
	public int y;
}
```
В примере выше, сначала в стеке выделяется память для state1 (и его полей, то есть state1.x и state1.y), затем создается ссылка для объекта country1, а с помощью ключевого слова new выделяется место в heap(куче). Ссылка для объекта country1 будет представляет адрес на место в heap, по которому размещен данный объект:
![[Stack&Heap2.png]]
Теперь предположим, что в структуре State, будет определенна переменная ссылочного типа Country:

```
struct State
{
	public int x;
	public int y;
	public Country country;
	public State()
	{
		x = 0;
		y = 0;
		country = new Country();
	}
}
```
значение переменной state1.country, также хранится в куче (т.к. эта переменная представляет ссылочный тип):
![[Stack&Heap3.png]]

# Копирование значений
Предположим у нас есть такой код:

```
State state1 = new State();
State state2 = new State();


state2.x = 3;
state2.country.x = 5;
state1 = state2;
state2.country.x = 8;
state2.x = 10;

Console.WriteLine(state1.country.x); //8
Console.WtireLine(state2.country.x); //8

Console.WriteLine(state1.x); //3
Console.WtriteLine(state2.x); //10

struct State
{
	public int x;
	public int y;
	public Country country; //описание класса Country есть выше
	public State()
	{
		x = 0;
		y = 0;
		country = new Country();
	}
}
```
