Весь код на языке C# помещается в файлы с расширением .cs. По умолчания в проекте создается один файл с кодом C# - Program.cs. Именно этот файл выполняется по умолчанию, если мы запустим проекта на выполнение.
# Инструкции
Инструкции(statement) - являются базовым строительным блоком программы. Она представляет некоторое действия например, арифметическую операцию, вызов метода, объявление переменной etc. В конце каждой инструкции в C# ставится точка с запятой. Этот знак указывает компилятору на конец инструкции.
Набор инструкций может объединяться в блок кода. Блок кода заключается в фигурные скобки, а внутри них помещаются инструкции. Так же фигурные скобки показывают область видимости к примеру:

```
{
	int a = 5;
}
	a = 10; //Ошибка, компилятор не видит переменную a, так как она в 
            //другой области видимости
```
# Регистрозависимость 
С# является регистрозависиммым языком. Это значит, что в зависимости от регистра (А-а) символов какие-то определенные названия могут представлять разные классы, методы, переменные.

```
 int a = 15;
 int a = 10;
 // Ошибка.
 //---------------------------------------
 int b = 15;
 int B = 10;
 // Позволительно;
```
# csproj
В каждом проекте на C# есть файл этот файл, он отвечает за общую конфигурацию проекта. По умолчанию он назваться projectName.csproj.
В файле проекта содержатся примерно такой XML код:

```
<Project Sdk="Microsoft.NET.Sdk">

  <PropertyGroup>

    <OutputType>Exe</OutputType>

   <TargetFramework>net6.0</TargetFramework>

    <ImplicitUsings>enable</ImplicitUsings>

   <Nullable>enable</Nullable>

	</PropertyGroup>

</Project>
```
Зависит от типа проекта, версии .NET Core/Framwork. В данном случае это консольный проект на версии .NET 6.0.
1. OutputType: определяет выходной тип проекта. Это может быть выполняемое приложение в виде файла с расширением .exe. И также это может быть файл с расширением .dll - некоторый набор фун-остей, который используется другими проектами.
2. TargetFramework: определяет применяемую для компиляции версию фреймворка .NET.
