Secure Key(Стойкий ключ) - это криптографический ключ, который:
	1.  Достаточно длинный, чтобы противостоять перебору;
	2. Случайно сгенерирован, чтобы его нельзя было угадать;
	3. Не изменяется слишком часто, чтобы не ослабить безопасность;
	4. Не передаётся в открытом виде, чтобы не был перехвачен;
# Как стойкий ключ используется?
1. Шифрование данных (AES, ChaCha20);
2. Электронная подпись (RSA, ECC);
3. Генерация одноразовых паролей (TOTP, HOTP);
4. Защита соединений (TLS, HTTPS, VPN);
## Как сделать ключ стойким?
1. Минимальная длинна:
	1. Для AES 128 бит (16 байт) - минимум;
	2. Рекомендуется 256 бит (32 байта);
2. Использование безопасных источников случайности:
	1. Только RNGCryptoServiceProvider(), RandomNumberGenerator.GetBytes(), а не Random();
3. Не хранить ключи в коде:
	1. Храните в защищённом хранилище (например, Windows DPAPI, HSM< Secure Enclave, TPM);
4. Менять ключи при необходимости:
	2. Если ключ скомпрометирован, его нужно заменить, а данные перешифровать;
