Hash-Function (Хеш-функция)  - это алгоритм, который принимает входные данные текст, файл, пароль) и преобразует их в фиксированную стоку (хеш-код, дайджест)
### Пример работы хеш-функции SHA-256

```
SHA-256("Hello, world!") → 64ec88ca00b268e5ba1a35678a1b5316...
SHA-256("Hello, world")  → 09ca7e4eaa6e8ae9c7d2611671291848...
```
## Как работаю Hash-Functions
1. Берут входные данные;
2. Применяют математические преобразования;
3. Выдают хеш([[Hash]]) фиксированной длины (128, 256, 512 бит etc.);
4. Невозможно восстановить исходные данные по хешу (односторонняя ф-ция);
# Свойства Hash-Functions
1. Фиксированная длина - независимо от размера входных данных, хеш всегда одинакового размера;
2. Детерминированность - одинаковый вход всегда даёт один и тот же хеш;
3. Чувствительность к изменениям - даже небольшое изменение входных данных полностью меняет хеш;
4. Устойчивость к коллизиям - сложно найти два разных входа, которые дают одинаковый хеш;
5. Односторонность - зная хеш, невозможно восстановить оригинальные данные;
