SHA-256(Secure Hash Algorithm 256-bit) - это криптографическая хеш-функция ([[Hash-Functions]]), которая:
1. Преобразует входные данные любой длинны в фиксированную строку из 256 бит (64 символа);
2. Невозможно восстановить оригинальные данные по хешу ([[Hash]]);
3. Изменения даже 1 бита полностью меняет результат (Свойство лавины );
4. Стойкость к коллизиям - сложно найти два разных входа с одинаковы хешем;
Пример работы SHA-256:
```
SHA-256("password") → 5e884898da28047151d0e56f8dc62927...
SHA-256("Password") → e7cf3ef4f17c3999a94f2c6f612e8a2a...
```
Изменился один символ -> Изменился полностью хеш([[Hash]]).
## Как работает SHA-256
1. Добавление дополнительных битов (Padding):
	1. Сообщение дополняется до длины кратной 512 битам;
2. Разбиение на блоки по 512 бит:
	1. Входные данные разделяются на блоки по 64 бита;
3. Обработка каждым из 64 раундов:
	1. Используются математические преобразования и логические операции (AND XOR, битовые сдвиги);
4. Формирование 256-битного хеша ([[Hash]]):
	1. Входной хеш([[Hash]]) имеет 64 шестнадцатеричных символа;
## SHA-256 в CSHARP
```
using System;
using System.Text;
using System.Security.Cryptography;

class Program
{
	public static string ComputeSHA256(string input)
	{
		using (SHA256 sha256 = SHA256.Create())
		{
			byte[] bytes = Encoding.UTF8.GetBytes(input);
			byte[] hashBytes = sha256.ComputeSahs(bytes);
			return BitConverter.ToString(hashBytes).Replace("-", "").ToLower();
		}
	}

	static void Main()
	{
		string text = "Hello, world!";
		string hash = ComputeSHA256(text);
		Console.WriteLine($"SHA-256: {hash}");
	}
}

```
Примерный вывод:
```
SHA-256: c0535e4be2b79ffd93291305436bf889314e4a3faec05ecffcbb9ace6e2c04f1
```
# Где используется SHA-256
1. Хранение паролей (Но лучше с солью и PBKDF2/Argon2);
2. Цифровые подписи и блокчейн (Bitcoin, Ethereum);
3. Проверка целостности файлов (Контрольные суммы);
4. SSL/TLS сертификаты (HTTPS);
