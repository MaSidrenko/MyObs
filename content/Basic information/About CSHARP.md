# О .NET
Основные черты платформы([[Framework]]'a) .NET:
1. Поддержка нескольких языков. Основой платформы является общеязыковая среда исполнения Common Language Runtime ([[CLR & CIL]]), благодаря чему .NET поддерживает несколько языков:
	1. С#;
	2. VB.NET (Visual Basic(Не используется));
	3. C++;
	4. F#;
	5. А также различные диалекты других языков, привязанных к .NET например Delphi.NET;
	При компиляции на любом из этих языков код компилируется в сборку на общем языке CIL(Common Inermedite Language)([[CLR & CIL]]).
2. Кросплатформенность. Используя различные технологии на платформе .NET можно разрабатывать приложения на языке C# для различных платформ:
	1. Windows 
	2. Linux
	3. MacOS
	4. Andoird
	5. IOS
3. Мощная библиотека классов(BCL (Base Class Library)). .NET представляет единую для всех поддерживаемых языков библиотеку классов.
4. Разнообразие технологий. Общеязыковая среда исполнения CLR и базовая библиотека классов является основой для целого стека технологий:
	1. Для работы с базами данных:
		1. ADO.NET;
		2. Entity Framework Core;
	2. Для построения приложений со сложным графическим интерфейсом:
		1. WPF;
		2. WinUI;
	3. Для более простых граф. приложений:
		1. WinForms;
	4. Для разработки кроссплатформенных мобильных и декстоп-приложений:
		1. Xamarin;
		2. MAUI;
	5. Для создания веб-сайтов и веб-приложений: 
		1. ASP.NET;
		2. Blazor;
5. Производительность;
Ещё следует упомянуть о Garbage Collection. Который реализует автоматическую сборку мусора. Из этого следует что, в отличии например от C++,зачастую нам не нужно заботится о освобождении памяти, об этом позаботится CLR([[CLR & CIL]])

Изначально .NET долгое время развивался как платформа под Windows и назывался .NET Framework. С 2014 года Microsoft стал развивать другую платформу: .NET Core, которая уже была кросплаформенной и включала в себя возможности .NET Framework, а так же добавить новую функциональность. 
## Управляемый и неуправляемый код
### Управляемый код
Управляемый код - это код, который выполняется под управлением CLR ([[CLR & CIL]])
Признаки управляемого кода:
1. Компилируется в CIL ([[CLR & CIL]]);
2. Исполняется CLR([[CLR & CIL]]) с помощью JIT или AOT;
### Неуправляемый код
Неуправляемый код - это код, который не управляется CLR, а исполняется напрямую ОС
Примеры:
1. Нативный C/C++ код
2. WinAPI
3. Ассемблер
.NET может взаимодействовать с неуправляемым кодом с помощью P/Invoke([[Basic information/PInvoke|P/Invoke]]) или COM Interop;
