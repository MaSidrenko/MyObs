# Побитовые операторы
## Операторы логического И(&)
Этот оператор, можно назвать "оператор логического умножения". Оператор & вычисляет побитовое логическое И целочисленных операндов. То есть, если два разряда числа равны 1, тогда и результатом вычисления будет 1, но если хотя бы один из разрядов будет равен 0, то и результат будет равен 0.
К примеру

```
int a = 248;
int b = 157;

Console.WriteLine(a & b);
```
Результат: 152;

## Оператор логического ИЛИ(|)
Этот оператор так же можно назвать "Оператор логического сложения". Оператор логического ИЛИ проводит логическую операцию над каждым разрядом числа.  То есть если хотя бы один операнд равен 1, то оператор вернет 1.
Пример:

```
int a = 248;
int b = 157;

Console.WriteLine(a | b);
```
Результат: 253;

# Операция логическое исключающее ИЛИ(^)XOR
Если значения текущего разряда у обоих числе разные, то возвращается 1, иначе возвращается 0
Пример:

```
int x = 45; 

int key = 102;

int encrypt = x ^ key;

int decrypt = encrypt ^ key;
```
x в двоичном формате = 101101;
key в двоичном формате = 1100110;
encrypt = 75, а в двоичном = 1001011;
decrypt = 45;
# ~(Логическая отрицание или инверсия)
Инвертирует все разряды: если значение разряда равно 1, то оно становится равным нулю, и наоборот.

```
int x = 12;                 `// 00001100`

Console.WriteLine(~x);      `// 11110011   или -13`
```
# Операции сдвига (<< >>)
Сдвиг может происходить как вправо так и влево:
1. x << y - сдвигает число x влево на y разрядов. Например: 4<<1 сдвигает число 4 (в двоичной системе = 100), на один разряд влево, то есть в итоге получается 1000 или число 8.(Умножаем на y)
2. x >> y - сдвигает число x вправо на y разрядов. Например 16 >> 1 (в двоичной системе 10000) на один разряд вправо, то есть в итоге получается 1000 или же 8;(Делим на y)
