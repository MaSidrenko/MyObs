  Искусственный интеллект (ИИ) - это теория и практика разработки алгоритмов, предназначенных для решение интеллектуальных задач, обычно решаемых людьми
Машинное обучение - подраздел искусственного интеллекта, в котором для решения интеллектуальных задач с помощью обучения на данных используются статистические методы
Глубокое обучение - подраздел машинного обучения, в котором для решения интеллектуальных задач используются глубокие нейронные сети
