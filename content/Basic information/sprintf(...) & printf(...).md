Ф-ция sprintf(dst, scr, patametrs); форматирует src-строку, и результат форматирования сохраняет в  dst-строку.
s.... - string; Как правило является форматиранной строкой 
Форматированная строка как правило содержит спецификаторы, которые подменяются соответствующими параметрами.
....f - format;
scr- Source (Строка источник);
dst - Destination(Строка Получатель);
printf(); - Print formatted string (Вывести на экран форматируемую строку)
%i - на место этого спецификатора вставляется значение типа 'int'
%s - на место этого спецификатора вставляется значение типа 'char* '
