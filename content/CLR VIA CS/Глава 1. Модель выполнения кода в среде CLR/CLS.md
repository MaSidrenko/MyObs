Если есть необходимость создавать типы, с которыми можно легко работать из других языков  программирования, придётся использовать только те возможности выбранного языка, которые доступны во всех остальных. Для упрощения этой задачи компания MIcrosoft определила спецификацию CLS(Common Language Speciiaction). В этой спецификации перечислен минимальный набор возможностей, которые должны поддерживаться компилятором для генерирования типов, совместимых с другими компонентами, написанными из других CLS-совместимых языках на базе CLR.

Полный список правил CLS приведен в разделе "Cross-Language Interoprebility" документации .NET Framework SDK(http://msdnmicrosoftcom/en-us/library/730f1wy3aspx).
Правила CLS в упрощенном в виде:
1. Каждый член типа является либо полем(данные) или методом(поведение) => каждый язык программирования должен уметь обращаться к полям и использовать методы
2. Некоторые поля и методы используются специальным образом
3. Для упрощения ЯП обычно предоставляют дополнительные абстракции, упрощающие реализацию этих стандартных паттернов:
	1. Перечисления (enum)
	2. Массивы
	3. Свойства
	4. Индексаторы
	5. Делегаты
	6. События
	7. Конструкторы
	8. Финализаторы
	9. Перегрузки операторов
	10. Операторы преобразования
	Когда компилятор встречает эти абстракции, он должен преобразовать их в поля и методы, что бы сделать их доступными для CLS и для других ЯП
