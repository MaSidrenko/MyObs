Поскольку типы занимают центральное место в [[CLR]] компания Microsoft разработала формальную спецификацию CTS(Common Type System), которая описывает способ определения и поведение типов.
Согласно спецификации CTS, тип может содержать нуль и более членов.
Краткие описания возможных членов:
1. Поле - переменная, являющаяся частью состояния объекта. Поля идентифицируются именем и типом.
2. Метод - ф-ция, выполняющая операцию с объектом, часто с изменением его состояния. Метод обладает именем сигнатурой и модификаторами. Сигнатура определяет количество параметров (и порядок их следования), типы параметров, наличие возвращаемого значения, и если оно имеется - тип значения, возвращаемого методом (string(int, string));
3. Свойство - с точки зрения вызывающей стороны выглядит как поле, но в реализации типа представляет собой метод (или два). Свойства позволяют организовать проверку параметров или состояния объекта перед обращением к значению и/или вычислять его значение только при необходимости. Кроме того, они упрощают синтаксис работы с данными и позволяются создавать "поля", доступные только для чтения или записи
4. Событие - используется для создания механизма оповещения между объектом и другими заинтересованными объектами. Например, кнопка может поддерживать событие оповещающее другие объекты о щелчке по ней

CTS также задет правила видимости типов и доступа к членам типа. Например, помечаю тип как открытый, тем самым он экспортируется и делается видимым и доступным для любой сборки.
Вот варианты ограничения доступа к членам типа:
1. Закрытый (private) - член типа доступен только для других членов того же типа
2. Доступ в семействе(protected) - член типа доступен для производных типов независимо от того принадлежат они той же сборке или нет.
3. Доступ в семействе и сборке - член типа доступен для производных типов, но только в том случае, если они определяются в  той же сборке. Многие языки(Например C#), не поддерживают этот уровень доступа. Разумеется в IL-код он поддерживается.
4. Доступ в сборке(internal) - член типа доступен для любого кода, входящего в туже сборку.
5. Доступ в семействе или сборке (protected internal) - член типа доступен для производных типов из любой сборки, а также для любых типов в той же сборке.
6. Открытый доступ(public) - член типа доступен для любого кода в любой сборке
