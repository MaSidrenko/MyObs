В процессе компиляции IL в машинные инструкции CLR выполняется процедура называемая верификацией - анализ высокоуровневого кода IL и проверка безопасности всех операций:
1. Убеждается в том, что каждый метод вызывается с правильным количеством параметров.
2. Все передаваемые параметры имеют правильный тип
3. Возвращаемое значение каждого метода используется правильно и каждый метод содержит инструкцию return 
Вся информация о методах и типах, используемая в процессе верификации, хранится в метаданных ([[Управляемый модуль]]) управляемого модуля
