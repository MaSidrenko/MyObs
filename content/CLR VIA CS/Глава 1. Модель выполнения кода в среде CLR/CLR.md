Common Language Runtime - исполняющая среда для байт кода CIL (Common Intermediate Language - низкоуровневый код (Ассемблер) виртуальной машины .NET), в который компилируется ПО, написанные на .NET
Основные возможности CLR:
1. Управление памятью;
2. Загрузка сборок;
3. Безопасность;
4. Обработка исключений;
5. Синхронизация;

Будут доступны в любых ЯП использующих эту среду.
Microsoft разработали компиляторы для следующих ЯП, используемых на платформе .NET Framework:
1. C++/CLI;
2. C#;
3. Visual Basic;
4. F#;
5. Iron Python;
6. Iron Ruby;
7. ассемблер Intermediate Language (IL);
