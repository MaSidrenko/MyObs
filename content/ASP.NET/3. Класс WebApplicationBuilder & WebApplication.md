# WebApplicationBuilder
Создание приложения по умолчанию фактически начинается с класса WebApplicationBuilder. Source Code: https://github.com/dotnet/aspnetcore/blob/main/src/DefaultBuilder/src/WebApplicationBuilder.cs
```
WebApplicationBuilder builder = WebApplication.CreateBuilder();
```
Для инициализация объекта WebApplicationBuilder в этот метод могут передаваться аргументы командной строки, указанные при запуске приложение (доступны через неявно определённый параметр args):
```
WebApplicationBuilder builder = WebApplicationCreateBuilder(args);
```
Либо можно передавать объект WebApplicationOptions:
```
WebApplicationOptions options = new() {Args = args};
WebApplicationBuilder builder = WebApplication.CreateBuilder(options);
```
Кроме создания объекта WebApplication класс WebApplicationBuilder([[2. Структура проекта ASP.NET Core]]) выполняет ещё ряд задач, среди которых можно выделить следующие:
	1. Установка конфигурации приложения 
	2. Добавление сервисов
	3. Настройка логирования в приложении
	4. Установка окружения приложения
	5. Конфигурация объектов IHostBuilder и IWebHostBuilder, которые применяются для создания хоста приложения
Для реализации этих задач в классе WebApplicationBuilder определены следующие свойства:
1. Configuration: представляет объект ConfigurationManager, который применяется для добавления конфигурации к приложению
2. Environment: предоставляет информацию об окружении, в котором запущено приложение.
3. Host: объект IHostBuilder, который применяется для настройки хоста
4. Logging: позволяет определить настройки логгирования в приложении.
5. Services: предоставляет коллекцию сервисов и позволяет добавлять сервисы в приложение
6. WebHost: объект IWebHostBuilder который позволяет настроить отдельные настройки сервера.
# WebApplication
Метод build() класса WebApplicationBuilder создает объект WebApplication:
```
WebApplicationBuilder builder = WebApplication.CreateBuilder();
WebApplication app = builder.Build();
```
Класс WebApplication применяется для управления обработкой запроса, установки маршрутов, получения сервисов. Source code: https://github.com/dotnet/aspnetcore/blob/main/src/DefaultBuilder/src/WebApplication.cs

Класс WebAppliction применяет три интерфейса:
1. IHost: применяется для запуска и остановки хоста, который прослушивает входящие запросы
2. IApplicationBuilder: применятся для установки компонентов, которые участвуют в обработке запроса
3. IEndpointRouteBuilder: применяется для установки маршрутов, которые сопоставляются с запросами

Для получения доступа к ф-ости приложения можно использовать свойства класса WebApplication: 
1. Configruation: предоставляет конфигурацию приложения в виде объекта IConfiguration
2. Environment: представляет окружение приложения в виде IWebHostEnvironment
3. Lifetime: позволяет получать уведомления о событиях жизненного цикла приложения
4. Logger: представляет логгер приложения по умолчанию
5. Services: представляет сервисы приложения
6. Urls: представляет набор адресов, которые использует сервер

Для управления хостом класс WebApplication определяет следующие методы:
1. Run(): запускает приложение
2. RunAsync(): асинхронно запускает приложение
3. Start(): запускает приложение
4. StartAsync(): запускает приложение
5. StopAsync(): останавливает приложение
Метод Run()/RunAsync() -> отслеживает жизненный цикл приложения сам. А Start/StartAsync() -> нужно останавливать вручную (Вызывать метод StopAsync())

Таким образом, после вызова метода Run()/Start()/RunAsunc()/StartAsync() приложение будет запущено, и мы сможем к нему обращаться:
```
WebApplicationBuilder builder = WebApplication.CreateBuilder();
WebApplication app = builder.Build();
app.Run();
```
При необходимость с помощью метода StopAsync() можно программным способом завершить выполнение приложения:
```
WebApplicationBuilder builder = WebApplication.CreateBuilder();

WebApplication app = builder.Build();

app.MapGet("/", () => "Hello World!");

await app.StartAsync();
await Task.Delay(100000);
await app.StopAsync(); // Через 10 сек завершаем выполнение приложения
```
