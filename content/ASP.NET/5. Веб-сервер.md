Как мы можем взаимодействовать с ASP.NET Core
![[Pasted image 20260204120345.png]]
Middleware -  конвейер обработки запросов. Различные элементы кода, которые помогают обрабатывать запросы 
Routing - определяет куда направить запрос
Security - различная защита: авторизация/аутентификация, двухэтапная аутентификация
Localization - определяет язык пользователя. В зависимости от языка, направляет различные данные 
Caching - HTTP(S) кеширование
Compression - сжатие данных, HTTP ответа
Session - Различные сессии пользователя 
![[Pasted image 20260204121124.png]]
Servers - веб серверы 
![[Pasted image 20260204121212.png]]
Самый популярный и современный Kestrel (кроссплатформенный). IIS и HTTP.sys - только на винде 
Hosting - где располагается приложение(Host). Работает с Dependency Injection. Делает различные фоновые задачи
