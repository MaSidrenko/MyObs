Булев куб для 3 переменных состоит из 8 наборов. Порядок - покоординатный:
набор альфа =< бета, если каждая координата альфа, не больше соответствующей координаты бета
Сравнимые наборы (Соединены путём вверх по стрелкам): 
Например: 000 <= 011 (Потому что 0 <= 0; 0<=1; 0<=1;)
010 <= 110
001 <= 011
101 <= 111
100 <= 110
Несравнимые наборы:
101 и 011
Потому что 1 <= 0 неверно
110 и 101 тоже несравнимы
![[Pasted image 20251203151929.png]]
Ф-ция f монотонна, если для любых сравнимых, наборов альфа <= бета, выполняется условие f(альфа) <= f(бета)
## Итог
Если мы можем перейти от одного набора к другому, заменяя какие - то 0 на 1 (и никого 1 на 0), то значение ф-ции недолжно уменьшается
