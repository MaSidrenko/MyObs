Материнская плата - это сложная многослойная печатная плата на которой устанавливаются основные компоненты ПК
На материнской плате расположены главные вычислительные устройства - ЦП, чипсет для управления потоками данных по шинам на материнской плате, ОЗУ, микросхема BIOS с хранимыми параметрами для функционирования ПК, слоты для подключения плат расширения. 
## Форм факторы
1. XL-ATX
2. ATX
3. Micro ATX
4. Mini-ITX
## Компоненты материнской платы
 - Разъем для установки ЦП(Сокет) (INTEL-LGA, AMD-PGA, BGA-припаянный ЦП)
 - Слоты расширения для установки ОЗУ
 - Разъем для подключения блока питания
 - Чипсет
 - Интерфейсы типа SATA (для подключения HDD и SDD)
 - Слоты расширения PCI (Сетевые карты HDD звуковой карты)
 - Разъемы для подключения периферийных устройств 
 - BIOS

## Чипсет
Чипсетом или набором логики называется основная интегральная микросхема материнской платы. Это своеобразный процессор, который связывает и управляет всеми устройствами платы
Ранее чипсетом были северный и южный мосты.
Северный мост, отвечал за более быстрее компоненты, а южный за более медленные компоненты.
## BIOS
BIOS - считается одной из важнейших микросхем системной платы. В ней находятся важные программы, требующиеся для первичной загрузки ПК. BIOS  необходим для проверки основных систем.
BIOS (Basic Input/Output System) — это базовая система ввода-вывода, набор низкоуровневых программ, хранящихся на специальной микросхеме материнской платы, который инициализирует аппаратное обеспечение компьютера при включении и загружает операционную систему
