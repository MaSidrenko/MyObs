Центральный процессор (CPU) - это электронное устройство (интегральная схема), которое выполняет и обрабатывает машинные инструкции, код программ и отвечает за все логические операции которые протекают внутри ПК

## Чип
Сам чип состоит из транзисторов, которые выполняют только одну ф-цию - быть включенными (1) или выключенными (0).
Закон Мура(Не действует) - количество транзисторов размещаемых на кристалле интегральной схемы удваивается каждые 24 месяца
## Характеристики ЦП
1. Тактовая частота - количество тактов в секунду (Измеряется в МГц и ГГц)
2. Разрядность ЦП - количество двоичных разрядов которые могут обрабатываться или передаваться ЦП одновременно - за 1такт(может быть 8,16,32,64 бита)
3. Производительность - скорость выполнения приложения ЦП(зависит от тактовой частоты и разрядности)
4. Тепловая мощность и энергопотребление
5. Системная шина - канал по которому ЦП соединен с другими устройствами ПК
6. Кэш память - это быстродействующая память, которая хранит информацию из ОЗУ для более быстрого доступа к ней (L1, L2, L3)
7. Сокет - разъем в который помещается ЦП
8. Количество ядер - это независимый блок, который отвечает за выполнение инструкций
9. Техпроцесс ЦП - это толщина транзисторного слоя, которая применяется в ЦП
## Архитектура ЦП
Архитектура ЦП - это компоновка транзисторов. Транзисторы объединяются в массивы - ядра. Каждое ядро в ЦП может независимо от других выполнять различные задачи, для этого регулярно повторяется цикл действий:
1. Получение информации
2. Раскодирование
3. Выполнение вычисления
4. Фиксация результата
## Виды архитектуры ЦП
1. RICS (Reduced Instruction Set Computer) - это подход, в котором используются простые и короткие команды.
2. CISC (Complex Instruction Set Comptuter) - данный вид включает в себя сложные и многоуровневые инструкции
3. MISC (Minimal Instruction Set Computer) - архитектура, использующая минимальное количество простых команд
4. EPIC (Explicitly Parallel Instruction Computing) - параллельная архитектура, позволяющая выполнять несколько команд одновременно

### Ядра
Ядро - является самой главной частью ЦП, которая обрабатывает все поступающие команды. Одно ядро может обрабатывать только один поток команд, и если в процессоре есть несколько ядер, то ОС может распределить на все ядра потоки команд.
## Число потоков
Число потоков - это параметр, который отвечать за то, сколько потоков информации может обрабатывать одно ядро ЦП
- **Ядро (Core)** — это **физический** компонент процессора, отдельный блок для выполнения вычислений. Можно представить его как отдельного рабочего на фабрике.
    
- **Поток (Thread)** — это **логический** компонент, последовательность команд (задача), которую нужно выполнить. Можно представить его как инструкцию (заказ) для рабочего.
## Виды ЦП
1. Универсальный процессор 
2. Серверные процессоры
3. Мобильные процессоры
4. Встраиваемые процессоры (Выполняют узкопрофильные задачи)
