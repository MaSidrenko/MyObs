Для работы с базой данных используется структурированный язык запросов(Structed Query Language (SQL)). SQL включает себя всего 7 запросов и эти 7 запросов можно разделить на две категории:
1. DDL - Data Definition Language (Язык определения данных) включает в себя 3 запроса:
	1. CREATE
	2. ALTER
	3. DROP
2. DML - Data Manipulation Language(Язык манипуляции данными) включает в себя 4 запроса:
	1. INSERT
	2. UPDATE
	3. DELETE
	4. SELECT
Работа с базами данных всегда обеспечивает какая то определенная система управления базами данных или же СУБД (DBMS - Data Base Management System). СУБД различают реляционные и не реляционные. К реляционным относятся: MySQL, Oracle, Microsoft SQL Server. Все эти СУБД являются серверными и обеспечивают доступ к БД одновременно множество клиентов, через локальную сеть и интернет. Есть так же персональные СУБД Microsoft access. Для подключения к серверу и для работы серверной СУБД у каждой СУБД существуют свои клиентские приложения у MySQL это MySQL WorkBench, у Oracle это Instant Client и у MS SQL Server это SSMS (SQL Server Management Studio)
Каждая СУБД имеет свою реализацию языка SQL например реализация SQL от Microsoft называется Transact-SQL
