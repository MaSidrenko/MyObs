# Язык Манипуляции данными
Включает в себя такие запросы как:
	1. INSERT
	2. DELETE
	3. UPDATE
	4. SELECT
## SELECT
Чаще всего используется запрос SELECT который имеет следующий синтаксис:
	SECELT columns FROM Tables;
colums and Tables перечисляются через запятую. Для того что бы выбрать все поля SELECT пишут так:
	SELECT * FROM Table;
DESC - Descending (В порядке убывания)
ASC - Ascending (В порядке возрастания)
## INSERT
Для вставки данных в таблицу используется запрос INSERT:
	INSERT Table(columns)
	VALUES         (values);
