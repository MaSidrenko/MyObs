Фреймворк для создания клиентской части webapp. Используя HTML CSS и C#. Blazor для создания приложений компонентно-ориентированный подход т.е. один компонент может использоваться сколько угодно раз. Для вызова компонентов в Blazor используется язык Razor. Razor плохо подходит для приложений которые будут открываться в  старых браузерах и на медленных интернет соединениях
