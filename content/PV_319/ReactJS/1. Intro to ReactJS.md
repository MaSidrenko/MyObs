Это JS [[Framework]], предназначенный для создания одностраничных приложений(SPA - Single Page Application). Этот фреймворк, разработан программистом и компании Facebook, работает на базе NodeJS, к особенностям ReactJS следующие:
1. Однонаправленная передача данных (Свойства передаются только от родительский элементов дочерним); Компонент получают свойства неизменяемых значений. Компонент не может изменять свойство непосредственно, но может это делать через callback ф-ции. 
2. ReactJS использует виртуальный DOM [[10. DOM]] React создает кэш структуру памяти, что позволяет определить разницу, между предыдущим и текущим состоянием интерфейса. И обновлять DOM браузера только при необходимости. Это повышает производительность страницы. Программист может считать, что страница обновляется полностью, но React сам решает когда и какие компоненты нужно обновить
3. JSX (JavaScript & XML) - это расширение синтаксиса JS который позволяет использовать синтаксис на подобии HTML для создания интерфейса. React использует так называемый компонентно-ориентированный подход. То есть любые интерфейсы в виде компонентов и повторно использовать сколько угодно раз с одинаковыми или разными данными, использование компонентов, использование компонентов синтаксически напоминает использование HTML тегов. 
4. У каждого компонента есть определенный жизненный цикл. По протяжении которого не явно вызываются определенные методы:
	1. shouldComponentUpdate();
	2. componentDidMount();
	3. render();
