Настоятельно рекомендуется в отдельной пустой папке, и в репозиторий включать только один проект, очень не удобно когда в одном репозитории несколько React-проектов, как минимум это делает невозможным хостинг React приложения на GitHub Pages. Следовательно каждый проект размещается в отдельном пустом каталоге и из этого каталога также делается репозиторий. Для создания проекта в выбранном пустом каталоге необходимо ввести команду: npx create-react-app .
Точка на конце показывает текущий каталог. При создании проекта создаются конфигурационные файлы: 
	1. .gitignore;
	2. package.json;
	3. package-lock.json;
	4. Каталог node-modules (Содержит минимально возможный набор React модулей);
	5. Каталог public (находится конечное приложение);
	6. Каталог scr (Исходные файлы и компоненты приложения);
Для запуска React приложения используется команда npm start
