ReactJS позволяет встраивать переменные значения не посредственно в HTML разметку, эти переменные, могут быть объявлены как не посредственно внутри компонента или же передаваться как параметры (props). Для удобства применения props можно применять деструктуризацию.
props могут иметь значения по умолчанию, которые описываются после тела ф-ции, до export default
### Синтаксис:
function Component(props) {
		return (
			//code;
		)
}

Component.defaultProps = {var1:value1, var2:value2, etc};

export default Comonent;
