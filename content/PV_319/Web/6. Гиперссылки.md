## Гиперссылки
Позволяют переходить на другие страницы или же на фрагменты той же страницы. Создаются при помощи парного тега <!a><!/a> - Anchor. Обязательным атрибутом этого тега является href (Hyper-reference). Этот атрибут указывает URL или же якорь на который нужно перейти. Если ссылка ведет на внешний ресурс, то её обязательно нужно открыть в новой вкладке, для этого необходимо тегу a необходимо добавить атрибут target="blanck". Значение # в атрибуте href обозначает текущею страницу. Относительно текущей страницы так же можно переходить по меткам и якорям. Для этого соответствующим тегам на которые мы хотим переходить, необходимо присвоить ID. Которое присваивается при помощи атрибута общего назначения id. ID с определенным именем можно назначить только одному элементу страницы
