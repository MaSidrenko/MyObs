DOM - Document Object Model. Представляет любую HTML страницу, как сложный объект. Который агрегирует в себя другие объекты - элементы страницы. 
DOM объединяет все элементы страницы в дерево объектов. Корневым объектом которого является объект 'documnet'. Этот объект всегда не явно создается в любом  JavaScript-коде. 
У каждого элемента на странице, есть 4 метода: 
1. append(element) - добавляет element в конец ноды ( Node - это узел дерева), а именно перед закрывающим тега;
2. prepend(element) - добавляет element в начало ноды, а именно после открывающего тега;
3. before(element) - добавляет element перед открывающим тегом;
4. after(element) - добавляет element после закрывающего тега;
