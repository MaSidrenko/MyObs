# JavaScript
Это язык программирования общего назначения с динамической типизацией данных. Исторически так сложилось, что JS используется в Web-разработке, но на самом деле он позволяет разрабатывать и самые обычные настольные приложения, для любой ОС. JS - интерпретируемый ЯП, т.е. программы написание на нём выполняются в исходном виде, без преобразования в машинные коды, а все программы на интерпретируемых языках, называют сценариями (Scripts). Кроме JS, интерпретируемые являются такие как: cmd, Bash. В связи с тем что JS как правило используется в Web разработке, его интерпретаторами являются браузеры. Т.е. любой браузер может исполнять JS-код. JS-код работает абсолютно везде где работает JS-интерпретатор. 
## Переменные
Переменные можно объявлять при помощи ключевых слов: 
1. var
	1. Объявляет глобальную переменную;
2. let
	1. Объявляет локальную переменную;
3. const
	1. Объявляет локальную константу;

Тип переменной не задается программистом, а задается при её определения, по типу значения сохраняемого в переменную. Тип любого значения, всегда можно узнать оператором typeof(varaible). Кроме строк, так же поддерживает следующие типы:
1. Number, может хранить как целые, так и дробные числа;
2. BigInt, хранит только целые числа, и поддерживает длинную арифметику;
3. Boolean, другие типы данных легко преобразуются в него. 0 - false, все что не 0 -true;
4. Undefined;
5. Null;
6. Symbol;
7. Object;
Многие типы, не явно преобразуются в строку
