## Введение
HTML - Hyper-Text Markup Language(Язык гипертекстовой разметки). Позволяет языковыми инструкциями описывать различные элементы интерфейса от самых простых до самых сложных (GUI - Graphics User Interface). HTML является интерпретируемым языком, а его интерпретаторами являются браузерами. Кроме HTML, для создания Web-страниц так же используется CSS (Cascade Style Sheet, Каскадные таблицы стилей). Это своего рода расширение языка HTML, позволяющие применять оформления ко множеству элементов страницы или интерфейса. 

## HTML
Язык HTML произошел от языка XML (Extensible Markup Language). От этого языка происходят абсолютно все языки разметки. Как и любой другой язык разметки состоит из descriptor(описатель) и tag(метка). Дескрипторы всегда пишутся в <>, они бывают парными и не парными. У парных тегов, есть открывающий и закрывающий тег
(
открывающий -> <тег> 
'code'
закрывающий -> </тег>
)
Иногда открывающий и закрывающий тег объединяют (<tag/>), так обычно делают, когда хотят использовать атрибуты этого тега.

## CSS
Для форматирования и оформления веб-страниц как правило используются стили CSS, а само содержимое страницы лишь используют заранее использованные CSS-стили. CSS позволяет применять форматирование как к самим тегам, так и к классам тегов созданных верстальшиком
Верстальшик - это человек который создает разметку. CSS-стили можно применять как локально так и глобально. Глобальные CSS-стили выносят в CSS-файл, который затем тегом link подключается к одной или нескольким страницам, один и тот же файл может оформлять несколько страниц. При необходимости так же можно применять локальные стили, при помощи атрибута общего назначения style
