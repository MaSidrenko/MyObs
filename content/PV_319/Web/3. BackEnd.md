 Веб приложения обладают не только внешним видом, но и неким функционалом, за который отвечает backend, который всегда работает на стороне сервера и основу эту backend части, как правило составляет БД([[Системы Управления Базами Данных(SQL)]]), но самой базы не достаточно, поскольку с ней ещё нужно как-то взаимодействовать и для этого взаимодействия могут быть использованы самые разные ЯП и технологии. Первым и по сей день популярным таким языком является php (Hypertext Preprocess), так же для взаимодействия на стороне с БД могут использоваться python приложения с фреймворком Django, Java с такими фреймворками как: Servlet, Spring, etc. C# использует технологию ASP.NET Core.
