Главное окно создается в три этапа:
	1. Регистрация класса окна - нужно объявить и проинициализировать класс WNDCLASSEX wc (Window Class), затем обнуляем память объекта ZeroMemory(&wc, sizeof(wc)). cb - Count Bytes
	2. Создание окна 
	3. Запуск цикла сообщений
# Ф-ция CreateWindowEx()
При помощи ф-ции CreateWindowEx() так же можно создавать и дочерние элементы интерфейса, поскольку они так же являются окнами. Важно только правильно указать класс окна и правильно определить стили окна (2 и 4 параметр). 
Класс окна может быть:
	1. Button
	2. ComboBox
	3. ListBox
	4. Edit
	5. Static
Это все встроенные системные классы окон. Так же множество классов доступны через Common controls
