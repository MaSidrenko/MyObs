Из множества открытых окон, только одно является активным, любое окно состоит из множества элементов управления, из этого множества элементов управления держит фокус. Фокус это часть окно которая принимает команды с клавиатуры. Фокус переключается при помощи клавиш tab, а иногда и при помощи клавиш курсора
