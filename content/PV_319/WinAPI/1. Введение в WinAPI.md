# WinAPI 
Точкой входа является ф-ция WinMain(), она всегда принимает 4 параметра:
	1. hInstance - экземпляр загруженного .exe-файла нашей программы
	2. hPrevInst - предыдущий запущенный экземпляр. Этот параметр уже не используется, и оставлен только для совместимости
	3. lpCmdLine - командная строка, с которой запустилась программа. Содержит имя исполняемого файла и параметры запуска, например:
		1. Имя открываемого файла
		2. URL Интернет-ресурса
		3. etc. 
	LPSTR - Long Pointer to String
	4. nCmdShow - Состояние окна при запуске, развернуто на весь экран, свернуто в окно, свернуто на панель задач.
