То есть в поле данных Ethernet кадра вложен IP пакет.
## Формат IP-пакета
![[IP Header.png]]
Version - версия протокола IP, всегда 4;
IHL - Internet Header Lenght. Содержит размер IP заголовка, в двойных словах(DWORD 4 байта). Минимально возможная длинна IP заголовка включающего в себя лишь обязательные поля составляет 20 байт, следовательно поле IHL как правило содержит значение 5;
TOS - Type Of Service содержит приоритет трафика, всего существует 8 уровней приоритета. Поле никогда не используется, и вряд ли когда либо будет использовать
Total Length - Общая длина IP - пакета, включая заголовок и поле данных. Измеряется в байтах. Максимальная возможная длина IP-пакета составляет 64 Килобайта, но как правило в сеть передаются пакеты не более 1500 байт.
Потому что в каждой ОС именно такой MTU
MTU - Maximum Transfer Unit
Следующие три поля (identification, flags, Fragment offset) отвечают за фрагментацию IP-пакетов. Фрагментация в том случае, когда фактический размер пакета, превышает MTU сети, через которую его нужно передать. 
Time to Live(TTL) - содержит время жизни IP-пакета, в так называемых Hops (Прыжки). Это поле по умолчанию содержит значения 64 или 128 в зависимости от ОС и декрементируется на каждом промежуточном маршрутизаторе. TTL позволяет избавится от заблудившиеся пакетов. Когда TLL= 0, протокол IP уничтожает пакет. 
Protocol - определяет тип протокола верхнего уровня. 
Например:
0x01 - ICMP 
0x06 - TCP
0x17 - UDP
Header checksum - контрольная сумма заголовка, вычисленная по алгоритму CRC-32. Это поле пересчитывается на каждом маршрутизаторе. 
Source addres - это IP адрес отправителя 
Destination adders - это IP адрес получателя
Все эти поля являются обязательными, то есть они всегда есть в любом IP пакете, но на этом формат IP заголовка не закачивается, у него есть не обязательное поле Options
