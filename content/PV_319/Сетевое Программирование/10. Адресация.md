В сетевых технология к адресам предъявляется 4 основных требования. 
1. Уникальность(Uniqueness) - говорит о том, что в сети нет двух одинаковых адресов, каждый адрес должен быть уникальным
2.  Компактность(Compactness) - говорит о том, что адреса не должны занимать много памяти, и чем меньше адрес тем проще с ним работать, это приводит к минимальным затратам ресурсов с адресами. 
3. Иерархичность (Hierarchy) - в адресе должны выделяется различные уровни 
4. Запоминаемость(Memorizability) - адрес должен легко читаться и легко запоминается человеком.

Адрес одновременно отвечающий всем требованиям не возможно, максимум можно создать адрес который отвечать двум иногда трём требованиям. Поэтому разработано несколько разных уровней адресации, для разных целей. Всего существует три типа адреса:
1. Символьные имена (DNS/NetBIOS);
2. Числовые адреса (IP/IPX);
3. Физические адреса (MAC);
Каждый из этих адресов используется для своих задач, и как правило у одного и того же узла сети присутствуют как минимум два типа адреса (Числовой и Физический). Для сопоставления используются специальные протоколы, например протоколы DNS/NetBIOS сопоставляют символьные имена числовым адресам, а IP-адреса с физическими адресами сопоставляется по протолку ARP (Addres Resolution Protocol).
## Физические или MAC адреса
MAC - Media Access Control (Управления доступом к среде передачи). MAC-адрес представляет число 6 байт, как правило в 16-чной системе счисления, байты при это разделяются либо -, либо :
Пример:
F8:9E:94:7E:65:DF;
Старшие (Первые) три байта являются кодом производителя(ManufacturerID), а младшие три байта (Последнее) обозначают серийный номер сетевой карты.
MAC-адрес присваивается сетевой карты её производителем, он зашивается в BIOS сетевой карты. То есть если на ПК установлено 5 сетевых карт, то у него будет 5 MAC-адресов
MAC-адрес всегда можно узнать при помощи команды getmac /v /fo list (в ОС Windows). Для проводных сетевых карт драйвер так же позволяет изменить MAC-адрес (В ОС Windows это можно сделать через диспетчер устройств). MAC - адреса работают на канальном уровне модели OSI, они видны лишь коммутаторам и лишь в пределах одной локальной сети. MAC-адреса невозможно использовать для адресации узлов в интернете, потому что для этого нужны числовые иерархические адреса. 
## Адресация в IP-сетях
Адресация в протоколах IP для определения целевого узла к которому отправляется IP пакет использует IP-адрес. IP-адрес - это число длиной 4 байта, означающие номер узла, уникальный номер узла, составной сети. IP-адрес соответствует требованиям уникальности, компактности и иерархичности. Последнее достигается за счет того ,что IP-адрес делится на номер сети и номер узла. Наиболее распространенной формой записи IP-адресов является точечно-десятичная нотация, при которой значения каждого байта, записывается в десятичной системе счисления и разделяется точками(192.168.100.200). Для деления IP-адреса, на номер сети и номер узла, за все время существования интернета использовалось несколько подходов:
1. Бесклассовая адресация - старшие два байта всегда являлись номером сети, а младшие два байта, всегда номер узла в этой сети. То есть в бесклассовой адресации IP-адрес имел следующий формат: N.N.H.H, где N - Network, H - Host(узел);
2. Классовая адресация - все адресное пространство разделяется на классы, каждый из которых выделяет разное количество байт для нумерации сетей и нумерации узлов. Всего существует 5 классов IP-адресов: A, B, C, D, E. Из которых для адресации узлов используются только первые три. Класс D - это Multicast-адреса, для группового вещания в интернете.E - Reserved, зарезервированные адреса. Классы IP-адресов отличаются двоичным префиксом старшего байта IP-адреса, что определяет диапазон принимаемых значений старшего байта IP-адреса.
	1. В классе A старший бит, старшего байта всегда равен 0 остальные биты изменяются, от всех 0 до всех 1 (Кроме старшего бита). Класс A отводит лишь один старший байт, для нумерации сетей, следовательно для нумерации узлов отводятся 3 младших байта. Формат класса A: N.H.H.H. В классе A может быть только 126 сетей по 16 777 216 узлов.
	2. В классе B старшие два бита, старшего байта всегда равны 10, остальные биты изменяются от всех нулей (1000 0000 - 128) до всех единиц (1011 1111 - 191). В классе B для нумерации сетей отводятся два старших байта, а для нумерации узлов, два младших байта N.N.H.H. Следовательно в классе B существует 16 384 сетей по 65 536 узлов
	3.  В классе C старшие три бита, старшего байта всегда равны 110, остальные биты изменяются от всех нулей (1100 0000), до всех 1 (1101 1111).Это определяет диапазон принимаемых значений старшего байта от 192 до 223. В классе C для нумерации сетей отводятся три старших байта N.N.N а для нумерации узлов, только младший байт .H (N.N.N.H). По этому классе C 2 097 152 сети по 256 узлов
Классы безусловно дают больше гибкости для разделения адресного пространства, по отношению с бесклассовой адресацией, которая очень расточительно использует IP-адреса и в начале 90 годов, этой гибкости даже хватало, но в современных реалиях, в которых у почти каждого человека есть несколько компьютеров, а то и несколько 10 компьютеров, и количество устройств в интернете значительно превысило диапазон int'a, класс перестали обеспечивать достаточную гибкость для распределения IP-адресов. Для более гибкого распределения адресного пространства появились маски.
3. Маска - это число длинной 4 байта, которое используется в паре с IP-адресом, и показывает, какие биты IP-адреса являются номером сети, а какие номером узла. То есть в отличии от классов, которые делят адрес, на номер сети и на номер узла, побайтово, маски делят адрес на номер сети и номер узла побитово. И биты IP-адреса которые в маске равны 1 являются номером сети, а те биты IP-адреса которые в маске равны 0 являются номером узла. Диапазоны бит отведенные под номер сети и номер узла могут быть только не прерывными. Маски так же как правило записывают в точечно десятичной нотации, но для большей наглядности и лучшего понимания, того как маска влияет на IP-адрес их переводят в двоичную систему счисления
Кроме точечно десятичной нотации маски так же часто записывают в виде префикса. Префикс показывает сколько бит в маске установлено в единицу, то есть сколько бит IP-адреса отводится под нумерацию сетей. Префикс по умолчанию для класса C будет 24.
