Ethernet - семейство технологий пакетной передачи данных между устройствами для компьютерных и промышленных сетей. Самый распространённый протокол в мер, используемый для построения локальных сетей (LAN) и городских сетей (MAN). Существует несколько версий протокола Ethernet, но все они работают по одному принципу. Ethernet использует кабельное соединение для передачи данных и использует адресацию [[5. MAC]](Media Access Control) для идентификации отправителя и получателя данных. 
Технология Ethernet работает следующим образом:
1. Устройство, которое хочет отправить данные, создает кадр данных, содержащий информацию для отправки;
2. Кадр данных отправляется на сетевой адаптер устройства, который преобразует его в электрический или оптический сигнал, подходящий для передачи по кабелю;
3. Сетевой адаптер отправляет сигнал по кабелю в коммутатор или маршрутизатор;
4. Коммутатор или маршрутизатор получает сигнал, проверят адрес MAC получателя и направляет кадр данных к соответствующему устройству
5. Устройство-получатель получать кадр данных, проверяет чексумму(FCS) и обрабатывает его
# Fast Ethernet
общее название для набора стандартов передачи данных в компьютерных сетях по технологии Ethernet со скоростью 100 Мбит/с. Иногда обозначается как 100BASE-X где X варианты реализации(100BASE-TX, 100BASE-FX). Для работы по витой паре имеют общее обозначение 100BASE-T
### Стандарты:
100Base-T - общий термин для обозначения стандартов, использующих в качестве среди передачи данных витую пару. Длина сегмента до 100 метров. Включает в себя стандарты 100Base-TX, 1000Base-T4, 100Base-T2.
100Base-TX - развития стандарта 100Base-T для использования в сетях топологии 'звезда' Задействована витая пара cat 5, используется только две неэкранированные пары проводников, поддерживается дуплексная передача данных, расстояние до 100 метров. 
100Base-T4 - стандарт использующий витую пару cat 3. Задействованы все четыре пары проводников. Передача данных идёт в полудуплексе.
100Base-FX - стандарт, использующий многомодовое волокно. Максимальная длина сегмента 400 метров в полудуплексе или 2 километра в полном дуплексе
# Gigabit Ethernet
в компьютерных сетях - термин описывающий различные технологии передачи Ethernet-кадр со скоростью 1Гбит/с, определяемые рядом стандартов группы IEEE 802.3
### Стандарты
Самой распространённой спецификацией является 1000Base-T(использует кабель UTP cat 5e) 
Так же широко получили распространение волоконно-оптического:
1000Base-T - основной гигабитный стандарт. Использует витую пару cat 5e. В передаче данных участвуют 4 пары каждая из которых используется одновременно для передачи в обоих направлениях со скоростью 250 Мбит/с. Расстояние до 100 метров
1000Base-SX - стандарт, использующий многомодовое волокно в первом окне прозрачности с длиной волны равной 850 нм. Дальность до 550 метров
1000Base-LX - стандарт использующий одномодовое и многомодовое оптическое волокно во втором окне прозрачности с длиной волны, равной 1310 нм. Дальность передачи в случае одномодового оптического волокна составляет до 5 км, а для многомодового 550 метров
1000Base-LH - стандарт использующий, одномодовое волокно. Дальность прохождения сигнала без повторителя до 100 км
# 2.5 и 5 Gigabit Ethernet
стандарты компьютерных сетей Ethernet со скоростью передачи данных 2.5 и 5 Гбит/с, использующие витую пару с медными проводами. Получили название 2.5 GBASE-T и 5 GBASE-T. Используют кабель cat 5e. Расстояние передачи 100 метров 
# 10 Gigabit Ethernet
группа технологий компьютерных сетей позволяющих передавать Ethernet-кадры со скоростью 10 Гбит/с. В отличие от предыдущих стандартов Ethernet в 10 Гбит вариантах определены только полнодуплексные связи. 
### Стандарты
10GBase-T - использует витую пару cat 6(максимальное расстояние 55 метров) и 6a(максимальное расстояние 100 метров)
