# SMTP/POPv3/IMAPv4
## SMTP(Simple Mail Transfer Protocol)
Простой протокол передачи почты. Работает по TCP-25. Используется как почтовыми клиентами, так и почтовыми серверами для отправки почтовых сообщений
## POPv3 & IMAPv4
Используется для получения писем с почтового ящика на сервере, на локальную машину, эту задачу выполняет почтовый клиент 
### POPv3 - Post Office Protocol
Выполняет синхронизацию с почтовым ящиком на сервере, с определенным интервалом, как правило 20 минут. Ориентирован на работу по медленному  соединению
### IMAPv4 - Internet Message Access Protocol
Протокол доступа к интернет сообщениям. Получает письма с сервера при их поступлении
