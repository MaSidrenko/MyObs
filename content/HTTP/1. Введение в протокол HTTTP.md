## HTTP (Hypertext Transfer Protocol) 
Представляет протокол для запроса ресурсов с веб-сервера. Когда мы обращаемся в веб-браузере к каким-либо веб-сайтам, мы как раз используем протокол HTTP.``
В .NET основной функционал по работе с протоколом HTTP сосредоточен в пространстве имен System.Net.Http, среди основных классов в котором следует отметить класс HttpClient (Класс, который позволяет отправляет запросы к веб-ресурсам) и класс HttpListener (Который выполняет роль веб-сервера)
