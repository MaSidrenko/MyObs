Для выполнения запросов класс HttpClient предоставляет ряд методов:
	1. Send()/SendAsync(): отправляет запрос в виде объекта HttpRequestMessage и получает ответ сервера в виде объекта HttpResponseMessage
	2. GeteAsync(): отправляет GET-запрос на указанный адрес и получает ответ сервера в виде объекта HttpREsponseMessage
	3. GetByteArraryAsync(): отправляет GET-запрос на указанный адрес возвращает ответ в виде массива байтов (byte[])
	4. GetStreamAsync(): отправляет GET-запрос на указанный адрес и возвращает ответ в виде объекта Stream
	5. GetStringAsync(): отправляет GET-запрос на указанный адрес и возвращает ответ в виде строки
	6. PostAsync(): отправляет POST-запрос на указанный адрес и получает ответ сервера в виде объекта HttpResponseMessage
	7. PutAsync(): отправляет PUT-запрос на указанный адрес и получает ответ сервера в виде объекта HttpResponseMessage
	8. PatchtAsync(): отправляет Patch-запрос на указанный адрес и получает ответ сервера в виде объекта HttpResponseMessage
	9. DeleteAsync(): отправляет DELETE-запрос на указанный адрес и получает ответ сервера в виде обхекта HttpResponseMessage
С помощью ряда свойств можно настроить базовые настройки отправки запросов:
	1. BaseAddress: Возвращает или устанавливает базовый адрес в виде объекта URI, который будет использоваться при отправке запросов.
	2. DefaultProxy: возвращает или устанавливает настройки прокси 
	3. DefaultRequestHeaders: возвращает или устанавливает коллекцию заголовков по умолчанию, которые отправляются на сервер при каждом запросе
	4. DefaultRequestVersion: возвращает или устанавливает версию протокола HTTP по умолчанию, которая применяется при отправке запросов
	5. DefaultVersionPolicy: возвращает или устанавливает политику версии по умолчанию
	6. MaxResponsecontentBufferSize: возвращает или устанавливает максимальный размер буфера в байтов при считывании данных ответа
	7. Timeout: возвращает или устанавливает тайм-аут перед отправкой запроса.
