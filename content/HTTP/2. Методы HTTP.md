1. OPTIONS(HttpMethod.Options): возвращает список остальных методов HTTP, которые поддерживает сервер для указанного адреса URL.
2. TRACE(HttpMethod.Trace): служебный метод, который просто повторяет исходный запрос, полученные сервером. Полезен для идентификации любых изменений, внесенных в запрос объектами в сети, пока запрос находится в пути.
3. CONNECT(HttpMethod.Connect): устанавливают туннель TCP/IP между исходным хостом и удаленным хостом.
4. GET(HttpMethod.Get): извлекает копию ресурса по URL-адресу, на который был отправлен HTTP-запрос.
5. HEAD(HttpMethod.Head): так же как и GET, извлекает копию ресурса по URL, только ожидает получения одних заголовков без тела ответа.
6. POST(HttpMethod.Post): предназначен для отправки данных в теле запроса для их сохранения в виде нового ресурса на сервере.
7. PUT(HttpMethod.Put): предназначен для отправки данных в теле запроса для изменения уже имеющегося ресурса на сервере.
8. PATCH(HttpMethod.Patch): предназначен для отправки данных в теле запроса для частичного изменения уже имеющегося ресурса на сервере.
9. DELETE(HttpMethod.Delete): предназначен для удаления ресурса по указанному адресу URL.
Если используется HTTP-метод, который не покрывает этими свойствами, то можно использовать конструктор, в который передается название метода:

```
HttpMethod customMethod = new HttpMethod("CUSTOM")
```
