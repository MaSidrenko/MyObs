Код для перемещения:
`private Rigidbody2D rb2;`

`private void Awake()`
`{`
	`rb2=GetComponent<Rigidbody2D>();`
`}`
`private void fixedUpdate()`
`{`


	`Vector2 inputVector = new Vector2(0, 0);`
	
	`if (Input.GetKey(KeyCode.W))`
	`{`
		`inputVector.y = 1f;`
	`}`
	`if (Input.GetKey(KeyCode.S))`
	`{`
		`inputVector.y = -1f;`
	`}`
	`if (Input.GetKey(KeyCode.A))`
	`{`
		`inputVector.x = -1f;`
	`}`
	`if (Input.GetKey(KeyCode.D))`
	`{`
		`inputVector.x = 1f;`
	`}`

	`rb2.MovePosition(rb2.position + inputVector* Time.fixedDeltaTime);`
`}`
Пояснение:
private Rigidbody2D rb2 - Создание физики
rb2=GetComponent<Rigidbody2D>() - Инициализация физики
Vector2 inputVector = new Vector2(0, 0) - Создание и инициализация вектора для движения
Input.GetKey(KeyCode.AnyKey) - считывание клавиши
inputVector - Изменение координат вектора
rb2.MovePosition(rb2.position + inputVector * Time.fixedDeltaTime) - Перемещение объекта 
rb2.position + inputVector - Считывается нынешнее положение объекта
rb2.position + inputVector * Time.fixedDeltaTime - Уменьшение частоты вызова ф-ции rb2.MovePosition(); (Уменьшение сокрости объекта)
